## Описание проекта

Страница «О себе» для студента-разработчика, созданная на HTML5 с использованием семантических тегов. Для базового оформления в `<head>` добавлен небольшой блок `<style>`.

## Структура страницы

- `<header>` - шапка с именем студента и заголовком страницы
- `<main>` - основной контент страницы
- `<section>` «Навыки» - маркированный список из 4 языков и технологий
- `<section>` «Проекты» - нумерованный список из 4 учебных проектов
- `<section>` «Обратная связь» - форма с полями «Имя», «Email», «Сообщение» и кнопкой отправки
- `<aside>` - боковая панель «Любимые технологии» (VS Code, Git, GitHub)
- `<footer>` - подвал с копирайтом и годом
- `<img>` - аватар с атрибутами `src`, `alt`, `width`, `height`

## Форма обратной связи

| Поле | Тип | name | placeholder |
|---|---|---|---|
| Имя | `text` | name | Ваше имя |
| Email | `email` | email | Ваш email |
| Сообщение | `<textarea>` | message | Ваше сообщение |

Кнопка отправки: `<button type="submit">`.

## Цветовая гамма

Сине-белая: основной цвет - синий (`#1e5aa8`), фон страницы - светло-голубой (`#f2f7fd`), блоки - белые.
